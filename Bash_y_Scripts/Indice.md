# Índice de Bash y Scripts

En esta sección damos el salto de escribir comandos sueltos en la terminal a juntarlos en un **script**: un archivo de texto que guarda una secuencia de comandos para ejecutarlos todos juntos cuando queramos. Aquí verás qué significa la línea mágica `#!/bin/bash`, cómo crear tu primer script paso a paso y cómo darle permisos para poder ejecutarlo. Cada enlace te lleva a una nota dedicada con explicaciones y ejemplos prácticos.
