# Filosofía del software libre

## ¿Qué es el software libre?

El software libre es aquel que respeta la **libertad del usuario**. No se trata del precio ("free" = libre, no gratis), sino de **libertad y control** sobre el programa que ejecutas.

- *Free as in "freedom", not as in "free beer".*
- Lo contrario del software **privativo** (código cerrado y controlado por una empresa).

Nota: Es la confusión más común: "libre" no significa "gratis". Puede haber software libre que se venda, y software gratuito que NO sea libre.

---

## Las 4 libertades del software libre

Definidas por la **Free Software Foundation**:

| # | Libertad | Significado |
|---|----------|-------------|
| **0** | Usar | Ejecutar el programa para **cualquier propósito**. |
| **1** | Estudiar | **Ver y modificar** el código fuente. |
| **2** | Distribuir | Compartir **copias** con quien quieras. |
| **3** | Mejorar | Distribuir tus **versiones modificadas**. |

<br>

> Las libertades 1 y 3 requieren acceso al **código fuente**.

Nota: Empiezan en 0 por tradición informática. Si falta cualquiera de estas cuatro, el software NO es libre.

---

## El "copyleft" y la licencia GPL

- La **GPL** usa el copyright al revés: en lugar de restringir, **garantiza** las libertades.
- Regla clave: si distribuyes software basado en código GPL, **debes** liberarlo también bajo GPL.
- Esto impide que alguien tome software libre y lo "encierre" en un producto propietario.

> **Copyleft:** la libertad se hereda y se protege a sí misma.

Nota: Es el mecanismo legal que mantiene libre al ecosistema. Garantiza que las mejoras vuelvan a la comunidad.

---

## ¿Por qué existen SO donde se paga por servicios?

El software libre y el negocio **no se contradicen**. Lo que se cobra no suele ser el código, sino el **valor añadido**:

- **Soporte técnico** y garantías (ej. Red Hat Enterprise Linux).
- **Mantenimiento, actualizaciones y seguridad** certificada.
- **Formación, consultoría e integración** empresarial.
- **Servicios en la nube** (AWS, Google Cloud, Azure corren sobre Linux).
- **Hardware** con el sistema preinstalado y certificado.

> Modelo: el software es libre, pero la **tranquilidad y el servicio profesional** tienen un precio.

Nota: Las empresas pagan por soporte porque necesitan a alguien responsable cuando algo falla en producción. Red Hat construyó un negocio de miles de millones sobre software libre vendiendo soporte, no código.
